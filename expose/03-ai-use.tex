\section{Planned Use of (Generative) AI}\label{sec:expose:ai-use}

Describe in which stages of your thesis you plan to use generative AI systems and for which purpose, e.g., reducing spelling mistakes, translating the abstract, or generating code for the prototype.
Name the tools and models you plan to use (e.g., Claude Code with Claude Opus 5.5).

Briefly discuss the potential risks of this use, e.g., incorrect or invented content, hidden plagiarism, or biased results, and explain how you control their impact on the scientific quality of your work, e.g., by reviewing all generated content and documenting the use in the declaration of AI use.
If you do not plan to use generative AI, state this instead.
